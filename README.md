## 实验一概要

在 sklearn 手写数字数据集（load_digits）上从零构建 MLP，通过基线 + 8 组对照实验 + 失败实验找到最优模型：

- 基线（1×32 Sigmoid + SGD 0.1）：22.22%
- 最优组合（ReLU + 2×128 + BatchNorm + Adam 0.001）：**95.65%**（3 次复测平均）
